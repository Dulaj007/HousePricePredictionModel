# 🏠 HousePricePredictionModel

A simple yet powerful **Supervised Machine Learning Regression** project that uses **Random Forest Regressor** to predict house prices 🧠📈.  
This project is perfect for beginners looking to understand how to train, test, and evaluate a basic ML model with real-world housing data.

---

## 🚀 Tech Stack Used

- 🐍 Python
- 📦 [Pandas](https://pandas.pydata.org/) - for data manipulation
- 🔍 [Scikit-learn](https://scikit-learn.org/) - for machine learning:
  - `train_test_split` for splitting data
  - `RandomForestRegressor` for modeling
  - `mean_absolute_error` for evaluation
- 🧪 Jupyter Notebook or any Python IDE (VSCode, PyCharm, etc.)

---

## 📂 Dataset

We used **Ames Housing Data** (`train.csv` and `test.csv`) which contains information like:

- 🏡 Lot area
- 📅 Year built
- 🛏️ Bedrooms
- 🚿 Bathrooms
- 🧱 Floor size  
  and many more!

##🔎 How It Works

- Load the data using pandas
- Select relevant features (like area, year, etc.)
- Split the data using train_test_split
- Train the model using RandomForestRegressor
- Evaluate the model using mean_absolute_error
- Predict prices on unseen data
